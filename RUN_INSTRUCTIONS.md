# Bharat Suraksha Connect — Source Code

This is the source extracted from the uploaded Lovable project.

## Stack
- React 19 + TypeScript
- Vite
- TanStack Start / TanStack Router
- Tailwind CSS v4
- Lucide React
- Recharts
- Radix UI components

## Run locally
1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run:
   npm install
4. Start:
   npm run dev
5. Open the local URL shown by Vite.

## Important
This prototype uses local React state/localStorage and illustrative demo data.
It does not send SOS cases to authorities and does not use a live government crisis feed.
Replace demo data and sample contacts with verified integrations before any real-world use.
